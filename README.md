Olist E-Commerce Analytics: 
Project Overview
This project analyzes the Olist Brazilian E-Commerce Dataset to understand customer satisfaction, delivery performance, and sales trends.
The project focuses on two main questions:
•	Can K-Means clustering identify meaningful groups based on customer satisfaction and operational characteristics?
•	Can historical sales data be used to forecast future revenue trends?
Tools & Technologies
•	Python
•	Pandas & NumPy
•	Matplotlib & Seaborn
•	Scikit-learn
•	Statsmodels
•	Jupyter Notebook
Analysis
The project includes:
•	Exploratory Data Analysis (EDA)
•	Customer satisfaction analysis
•	Delivery performance analysis
•	K-Means clustering
•	PCA visualization
•	Sales trend analysis
•	Time-series forecasting
Key Findings
•	Longer delivery times and delays were associated with lower customer review scores.
•	K-Means identified four distinct transaction clusters.
•	The largest cluster represented transactions with high customer satisfaction and strong delivery performance.
•	Historical revenue showed an overall growth trend.
•	Multiple forecasting models were evaluated to analyze future sales performance.
